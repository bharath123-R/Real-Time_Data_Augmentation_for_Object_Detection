Real-Time Object Detection and Voice Assistance System using YOLOv8 and MATLAB

Description

Developed a real-time object detection system using YOLOv8 integrated with MATLAB and live webcam feed processing. The system detects objects with high accuracy using deep learning techniques and converts detected object labels into voice output through a text-to-speech module (TVoice). Designed mainly for assistive applications and real-time monitoring systems with low latency and efficient performance.

Key Responsibilities / Features
Implemented real-time object detection using YOLOv8 model.
Integrated webcam video acquisition and frame processing in MATLAB.
Developed voice feedback functionality using text-to-speech technology.
Improved accessibility support for visually impaired users.
Achieved efficient low-latency detection and audio response.
Designed an integrated AI-based computer vision framework.
